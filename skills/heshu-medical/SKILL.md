# Heshu Medical — 鹤叔生活医疗科普

基于鹤粉整理的「仙鹤大叔医疗科普合集」的知识参考库，覆盖 130+ 条皮肤病/日常小病的家庭护理方案。

## ⚠️ 用前必读（不可跳过）

**本 skill 承载的是民间医疗科普笔记，非专业医学指南。**

使用此 skill 时你 **必须** 遵守以下规矩：

1. **每次回答末尾必附免责，无豁免**：模板 — _"以上为民间科普参考，非专业诊断。症状不明或加重请及时就医。"_
   - ⚠️ **此免责无任何豁免场景**：简单问题、口诀问题、药品名查询、"倒刺怎么处理"这类看似无关紧要的问答，**一律附加**。不得以"回答简短"或"显然没事"为由省略。
2. **不替代医生决策**：可陈述鹤叔方案，但**不为用户拍板**"要不要吃/用"
3. **不开处方式口吻**：改"推荐用 X 毫克"为"鹤叔笔记中提到 X 毫克的用法，具体需咨询医生"
4. **红线场景必须先建议就医**（见下文）后再给参考信息
5. **儿童用药、激素类药物、孕妇**：必须加上"建议在医生指导下使用"
6. **涉及强的松片剂量时**：以 `03-glossary.md` 为准（**15 毫克/日**，片剂）；源 md 第 63 行"15 毫升"为液体单位笔误，**勿转述**

## 工作流程

### 步骤 1：先读索引

用户提问皮肤/外伤相关问题时，**第一件事是读 `references/00-index.md`**，按"症状 / 疾病 / 药品 / 口诀"反向定位。

### 步骤 2：按指针读具体条目

索引中的 `[01]` / `[02]` / `[03]` 指向：

- `[01]` → `references/01-douyin-kepu.md`（第一篇抖音短视频 93 条）
- `[02]` → `references/02-live-kepu.md`（第二篇直播汇总，6 大类 41 条）
- `[03]` → `references/03-glossary.md`（药品/耗材词典 + "坐等还书"口诀）

**⚠️ 索引未命中时的处理**：

- 若 `00-index.md` 无精确命中，**必须在回答开头声明**：_"鹤叔笔记中未直接覆盖此症状。以下为参考相近条目，可能不完全适用。"_
- 若仅找到模糊相似的条目（如用户问口周白色脓疱，索引仅有口周皮炎/唇炎），**必须标注**：_"以下条目症状相近但非完全对应，请以医生诊断为准。"_
- **禁止静默套用**最接近条目——CC 不得在未声明的情况下把"口周皮炎"的方案用在用户的"口周白色脓疱"上
- 若多个候选条目都触发就医红线，**优先建议就医**，再给参考方向

## 使用规约（细则）

### 关于用药描述

- **可以**引述鹤叔配方（如"500ml 水 + 5 片盐酸小檗碱 = 标准黄连素水"）
- **不要**把配方改成"处方"口吻（"你应该吃"、"你必须用"）
- **必须**提示非处方药也有禁忌（如碘伏禁忌详见 `[01] 第 35、40 条`）

### 关于辨别

- 当用户描述的症状在多条目中类似时（如湿疹 vs 荨麻疹 vs 痱子 vs 皮炎），**先提供辨别要点**，再给方案
- 辨别要点从索引 00 对照多条查找
- 若辨别后仍无法确定归属，或多个候选均触发就医红线，**应优先建议就医**，再给参考方向，不强行归类

### 关于药品名称歧义

- **乐肤液 ≠ 乐肤杀菌液**（反复强调，参考 `[03]`）
- **医用碘伏（1%）≠ 药店普通碘伏**（可能浓度偏低或偏高）
- **盐酸小檗碱 ≠ 复方黄连素片**（治疗激素脸场景差异大，参考 `[01] 第 67 条`）
- 涉及此类时务必标注

### 关于"坐等还书"等口诀

- 真菌类问题（脚气、股癣、体癣、汗斑）**优先提口诀**：唑 → 环 → 另一种唑 → 舒
- 痤疮问题提："红头脓头用碘伏，白头黑头十滴水"（参考 `[01] 第 55 条`）

### 关于儿童与老人

- 婴幼儿问题优先参考 `[01] 第 2-8、30、45-47、85 条` 等小儿专题
- 65+ 老人皮肤问题避免激素类药物推荐，建议医生评估

## 不适用场景（skill 要拒绝介入）

- 内科/外科/妇科/精神科等**非皮肤表面**问题
- 需**影像学/化验**确诊的问题（如肿瘤、自身免疫病）
- 用户明确**已就医、医生有明确方案**，只想咨询依从性 — 以医生方案为准
- **涉及药物剂量精确到"一定要吃多少"**的问题 — 一律返医

此类场景应**委婉劝返**："此问题超出鹤叔笔记覆盖范围，建议当面就医。"
