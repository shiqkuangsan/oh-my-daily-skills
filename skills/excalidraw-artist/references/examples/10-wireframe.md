# Wireframe Example

Product dashboard wireframe with page frame, sidebar navigation, header actions, KPI cards, chart placeholder, and activity table.

**Layout model:**

- Outer frame represents a browser/app viewport
- Sidebar + header define persistent navigation regions
- Main content uses card blocks with low-detail placeholders

**Key techniques demonstrated:**

- Use low-fidelity blocks for layout decisions before visual detail
- Bind labels to major UI containers so moving a region keeps the label attached
- Keep decorative separators as `line` elements instead of arrows
- Use neutral colors for layout, with restrained semantic accents for active navigation and primary action
