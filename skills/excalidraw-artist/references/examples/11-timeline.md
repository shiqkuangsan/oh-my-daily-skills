# Timeline / Gantt Example

Release timeline with month columns, lane labels, task bars, dependency arrows, and a launch milestone.

**Layout model:**

- Time runs left to right across equal month columns
- Workstreams are rows; task bars span their scheduled window
- Dependency arrows connect task bars, while lane separators stay decorative lines

**Key techniques demonstrated:**

- Separate timeline columns from swimlane rows
- Use bars for duration and a diamond for milestone events
- Keep dependency arrows bound to task bars so schedule edits remain connected
- Use decorative `line` elements for lane separators
